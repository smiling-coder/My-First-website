# My-First-website
Infosys Career Cracker
A personal placement-prep coach for BCA students aiming for software roles, including Infosys. It tracks your real progress, plans each day around your weakest areas, and gives you an honest readiness score.

Live demo: https://smiling-coder.github.io/infosys-career-cracker/

Why I built it
Most prep apps are course libraries or quiz banks. This one works like a coach: it asks what you need next, gives you a daily mission, makes you attempt things before showing answers, and never inflates your score.

Features
Personal profile: semester, skills, study hours and target role shape your plan.
Dashboard: readiness ring, skill radar, streak, next best action, and weekly activity. Cards can be dragged to rearrange, and the layout is saved.
Daily mission: coding, aptitude, technical, project, GitHub, communication and revision tasks. Tasks move through Start, In Progress and Completed.
Adaptive plan: weaker skills get focus tasks, so every student's roadmap differs.
Problem solving: 15 coding problems from beginner to advanced, run against test cases in the browser, with hints on request, solution after your attempt, and time and space complexity.
Aptitude lab: timed quantitative, logical and verbal tests with topic-wise accuracy and explanations.
Project builder: 9 projects across three levels, unlocked milestone by milestone, with a 12-point quality checker scored out of 100.
GitHub trainer: Git lessons, weekly assignments, a readiness score, and a portfolio checklist.
Resume builder and reviewer: ATS score, four resume versions, and a rule-based reviewer. It only uses facts you enter.
Interview room: technical and HR simulators that ask one question at a time with feedback and follow-ups, project defense mode, and an English speaking trainer with optional voice input.
AI-style career mentor: answers from your own progress data.
Journey, gap analyzer, job readiness and badges: shows where you stand against a general fresher-role skill list.
Light and dark mode, mobile-first layout, keyboard-accessible controls.
Honest by design
The readiness score comes only from work you complete.
The app does not promise a job, a salary or selection.
All questions are practice material or app-generated simulations, not real company papers.
Skill targets are general industry expectations, not an official Infosys checklist. Check the official Infosys careers site for current recruitment details.

Tech stack
HTML, CSS and vanilla JavaScript in a single index.html
No backend and no build step
Progress is stored in the browser's localStorage

Run locally
Clone the repo: git clone https://github.com/smiling-coder/infosys-career-cracker.git
Open index.html in your browser.

Deploy
Push to GitHub, then open Settings → Pages, choose the main branch and / (root), and save.

Known limitations
Coding problems use JavaScript so they can run in the browser. The logic carries over to Python and C#.
Data lives on one device and browser. There is no login or sync yet.
The mentor and interview feedback are rule-based, not a live AI model.
